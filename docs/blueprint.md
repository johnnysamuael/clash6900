# **App Name**: Clash Coin Central

## Core Features:

- Media Carousel: Display all provided media (images, videos) in an automatically rotating carousel at the top of the page.
- Coin Info Section: Dedicated section presenting key information about $CLASH6900 (description).
- Embedded Media Gallery: Embed various media content pieces (images, videos, articles) throughout the website's content sections.
- Social Media Links: Prominent links to all relevant social media channels and community platforms related to $CLASH6900.
- Clash Content Summary: Use generative AI to provide concise summaries of Clash Royale-related articles and videos when provided as input using a tool.

## Style Guidelines:

- Primary color: Vibrant gold (#FFD700), representing the value and opportunity associated with the coin.
- Background color: Dark gray (#282828) to create contrast and a premium feel.
- Accent color: Electric blue (#7DF9FF) used for highlights and interactive elements.
- Body and headline font: 'Space Grotesk', a sans-serif, for a tech-forward, contemporary style.
- Clean and modern layout with clear sections for different types of content. Prioritize readability and visual appeal.
- Use icons related to Clash Royale where relevant, such as card symbols or troop silhouettes, in a simple and recognizable style.
- Subtle animations on the carousel transitions and button hovers for a polished user experience.
